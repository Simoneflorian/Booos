1. So melden sich Ihre Kunden an

Eine schlanke Anmeldeseite im Design Ihres Betriebs. Der Link kommt auf die Website, in die E-Mail-Signatur und auf Rechnungen. Für die Ladentheke und den Firmenwagen gibt es einen A5-Aushang mit QR-Code.

  • Auf dem Handy in unter einer Minute ausgefüllt
  • Rechtssicher aufgebaut: Einwilligungstext, Double-Opt-in, Abmeldung jederzeit möglich
  • Fragt gleich Heizungsart und letzte Wartung ab, damit die Erinnerung zum richtigen Zeitpunkt kommt
  • Kein Tracking, keine Cookies

      4. Die Automatik dahinter

      Aus der Kundenliste wird jeden Tag berechnet, wer heute welche Mail bekommt. In der Demo übernimmt das ein kleines Skript mit 15 erfundenen Kunden. Im echten Betrieb richte ich die gleiche Logik in Ihrem Versandtool ein, zum Beispiel bei einem deutschen Anbieter mit Server in der EU.

      $ npm run plan -- --stichtag 2026-10-06 Datum Status Kunde Name Mail Wartung fällig 06.10.2026 ▶ heute senden K001 Anna Beispiel 3 · Wartungserinnerung 03.11.2026 06.10.2026 ▶ heute senden K004 Dieter Fiktiv 5 · Bewertungsanfrage 04.10.2027 06.10.2026 ▶ heute senden K008 Hans Vorlage 2 · Willkommen 06.10.2026 ▶ heute senden K015 Olga Prototyp 7 · Reaktivierung 19.08.2025 13.10.2026 geplant K002 Bernd Probe 4 · Letzte Erinnerung 20.10.2026 13.10.2026 geplant K010 Jürgen Entwurf 3 · Wartungserinnerung 10.11.2026 … Hinweise: K007 wartet auf Bestätigung · K008 Datum der letzten Wartung fehlt · K011 abgemeldet

      Gekürzte Beispielausgabe. Das Skript gibt den Zeitplan zusätzlich als JSON aus und erzeugt auf Wunsch die fertig personalisierte Mail für einen Kunden (npm run plan -- --kunde K001). Es wird nichts verschickt.

      Das möchten Sie auch für Ihren Betrieb?

      Ich passe alles an Ihren Betrieb an: Name, Logo, Farben, Texte und Leistungen, zum Beispiel für Wartungsverträge, Badsanierung oder Klimaanlagen. Ich richte das Versandtool ein und übernehme Ihre bestehende Kundenliste, sofern dafür Einwilligungen vorliegen.
